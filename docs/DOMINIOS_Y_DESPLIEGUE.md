# Dominios y despliegue — decisiones pendientes

## Recomendación de arquitectura

Usar un solo dominio principal para todo el ecosistema y conservar las rutas actuales:

- `/el-charro-funk`
- `/funky-burgers`
- `/pachakana`
- `/originalidad-estilo-esencia`

Esta opción mantiene juntas las cuatro experiencias, reduce costos de dominio y facilita la navegación, el mantenimiento y la medición. No hace falta comprar un dominio diferente para cada landing en la primera etapa.

## Dominios a validar con la clienta

1. Dominio principal de Charrofunka Company, con el nombre y ortografía legal/comercial aprobados.
2. Dominios defensivos o de campaña para El Charro Funk, Funky Burgers, Pachakana u OEE solamente si la clienta quiere promocionarlos de forma independiente; pueden redirigir a la ruta correspondiente del dominio principal.
3. Variante corta para Batallas Neoprimitivas únicamente si se usará en campañas, impresos o boletaje.

La disponibilidad, titularidad, precio y posibles conflictos de marca deben revisarse justo antes del registro. No se ha comprado ni reservado ningún dominio.

## Despliegue

- Las landings pueden publicarse juntas desde este repositorio y un solo proyecto de hosting.
- Dominio, hosting, configuración DNS, despliegue productivo y servicios de terceros se cotizan por separado del diseño y desarrollo de las landings.
- Antes de publicar se necesitan: dominio elegido, acceso del titular, teléfono y enlaces oficiales, contenido aprobado, imágenes finales de merch, información de premios, catálogo completo de servicios y textos legales aplicables.
- El bloque de planes/boletos de OEE permanece en modo demostración hasta que se confirme plataforma, precios, condiciones y aviso de privacidad.
